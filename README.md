# Geoinformatik 2 · Hochschule Mainz

Prof. Dr. Yu Feng · [yu.feng@hs-mainz.de](mailto:yu.feng@hs-mainz.de)

In diesem Repository finden Sie die Materialien zu den Übungen der Lehrveranstaltung **Geoinformatik 2**. Sie entwickeln eigene Web-GIS-Anwendungen und lernen Methoden zur Analyse räumlicher Daten kennen.
